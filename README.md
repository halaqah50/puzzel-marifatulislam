# Ma'rifatul Islam - Game Puzzle Interaktif

Game puzzle edukasi Islami interaktif yang menggabungkan permainan susun gambar landmark masjid-masjid terkenal di dunia (seperti Masjidil Haram, Masjid Nabawi, Masjid Al-Aqsa, dan Masjid Istiqlal) dengan kuis ilmu pengetahuan Islam (*Ma'rifatul Islam*).

## 🌟 Fitur Utama

- **Kuis Ma'rifatul Islam**: Lebih dari 130+ soal seputar Akidah, Fiqih, Sirah Nabawiyah, Al-Qur'an, dan Pengetahuan Umum Islam.
- **Puzzle Landmark Masjid**: Pilihan gambar masjid megah dengan tingkat kesulitan grid yang dapat disesuaikan.
- **Mekanik Edukasi Interaktif**: Jawab pertanyaan dengan benar untuk membuka kepingan puzzle, lalu susun kepingan hingga gambar masjid utuh sempurna.
- **Sistem Skor & Streak**: Dapatkan poin bonus dan pantau statistik ketepatan serta waktu permainan.
- **Landmark Info & Edukasi**: Pelajari sejarah dan fakta menarik dari setiap landmark masjid setelah berhasil menyelesaikannya.

## 🚀 Teknologi yang Digunakan

- **React 19** + **TypeScript**
- **Vite** (Build tool)
- **Tailwind CSS v4**
- **Motion** (Framer Motion)
- **Lucide React** (Ikon)
- **Canvas Confetti**

## 🛠️ Cara Menjalankan Project

1. Install dependensi:
   ```bash
   npm install
   ```

2. Jalankan mode pengembangan (development mode):
   ```bash
   npm run dev
   ```

3. Buka browser pada alamat `http://localhost:3000`.
